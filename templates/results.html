These checks ensure your syllabus works well for students using screen readers or other assistive technology. Many of these can be fixed quickly in Word.

Why Syllabus Accessibility Matters

A syllabus is often the first document students encounter and serves as a contract, roadmap, and accessibility gateway. Inaccessible syllabi disproportionately affect students with disabilities, international students, first-generation students, and neurodivergent learners.

Our accessibility checks are based on established standards from leading organizations:

Document Accessibility Standards:
  • WCAG 2.1/2.2 - International accessibility guidelines (W3C/WAI)
  • Section 508 - U.S. federal accessibility requirements
  • ADA - Americans with Disabilities Act compliance
Educational Best Practices:
  • UDL - Universal Design for Learning (CAST)
  • Quality Matters - Course design standards
  • AEM Center - Accessible Educational Materials
Font Usage
  • Small font sizes (below 11pt)
  • Decorative or inaccessible fonts
  • Inconsistent font families

Fix: Select text → Home → Font size 11pt+. Use Arial, Calibri, or Times.

Table Checks
  • Table Headers — missing designated header row
  • Table Scope — header row not marked as repeating
  • Table Captions — missing caption/Alt Text description
  • Layout Tables — tables used for layout instead of data
  • Empty Rows/Columns — blank rows/columns used for spacing
  • Merged Cells — cells that break screen reader navigation
  • Reading Order — complex structure confusing to navigate
  • Color Coding — colors conveying meaning without text labels
  • Embedded Images — images in cells with minimal text
  • Numeric Alignment — inconsistent number alignment

Fix: Each table issue type has its own fix instructions above.

Color & Contrast
  • Low color contrast
  • Color used as sole indicator of meaning
  • Text over colored backgrounds

Fix: Use dark text on light backgrounds. Add text labels if using color for meaning.

Links
  • Non-descriptive link text ("click here")
  • Long URLs in text

Fix: Right-click link → Edit Hyperlink → Change display text to something descriptive.

Text Formatting
  • Pseudo-tables (manual alignment with tabs/spaces)
  • Underlined non-link text
  • Insufficient line spacing
  • Full text justification
  • Large blocks of ALL CAPS text
  • Excessive bold, italic, or underline
  • Inconsistent formatting

Fix: Use left alignment. For emphasis, use bold instead of ALL CAPS or underline.

Images & Alt Text
  • Missing alt text
  • Questionable decorative image marking
  • Images containing text or schedules
  • AI-powered alt text quality analysis
  • Logos with insufficient descriptions

Fix: Right-click image → "View Alt Text" → Add description.

Document Properties
  • Missing document title
  • Missing language setting
  • Multiple languages without proper tagging

Fix: File → Info → Properties → Add Title.

Content Quality
  • Copied content with broken formatting
  • Footnotes instead of inline explanations
  • Visual indicators without text equivalents
  • Math expressions without accessible markup

Fix: When pasting, use Ctrl+Shift+V or "Paste Special" → "Keep Text Only".

Legal Compliance: These checks help institutions comply with federal accessibility laws (ADA, Section 504, Section 508).
